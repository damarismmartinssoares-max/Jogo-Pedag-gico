# Missão: Escola em Equilíbrio

Jogo pedagógico colaborativo para formação de Coordenadora Pedagógica e Orientadora Pedagógica.

## Arquivos
- `docs/index.html`: jogo completo, com HTML, CSS e JavaScript no mesmo arquivo.
- `docs/.nojekyll`: arquivo auxiliar para publicação estática no GitHub Pages.

## Como publicar gratuitamente no GitHub Pages

1. Entre em [github.com](https://github.com/) e faça login ou crie uma conta.
2. Clique em **New repository**. Escolha um nome, por exemplo `missao-escola-em-equilibrio`, e crie o repositório.
3. Envie a pasta `docs` e o arquivo `README.md` para a raiz do repositório. A estrutura deverá ficar assim:
   - `docs/index.html`
   - `docs/.nojekyll`
   - `README.md`
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/docs`; clique em **Save**.
7. Aguarde o GitHub concluir a publicação. O endereço aparecerá na própria página de configurações.

## Como acessar e compartilhar
O endereço terá o formato:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

Substitua `SEU-USUARIO` pelo seu nome de usuário real do GitHub e `NOME-DO-REPOSITORIO` pelo nome que você escolheu. Não é necessário informar esses dados antes de publicar: o GitHub Pages exibirá o endereço correto.

## Como jogar
- Abra `docs/index.html` diretamente no navegador, ou use o endereço publicado.
- Clique em **Começar missão**.
- As cartas são embaralhadas a cada nova partida.
- Em cada situação, conversem e selecionem uma resposta para as seis decisões.
- Se houver respostas a rever, o jogo mantém a mesma situação e destaca as escolhas para revisão. Não retira casas nem pontos.
- A missão só avança com seis decisões corretas.
- O desafio final pede que organizem três demandas simultâneas por prioridade, liderança e acompanhamento.

## Observação formativa
As respostas consideradas adequadas são uma proposta pedagógica para apoiar a conversa, não substituem protocolos institucionais, orientações da direção ou procedimentos de emergência. Em situações de saúde ou risco à segurança, sigam imediatamente os protocolos da instituição e acionem os serviços competentes.
